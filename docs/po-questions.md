# Questions for the Product Owner

**For:** the Product Owner. Every question is written in everyday words: what happens, what the spec
says, what the app does today, and the choices. There are no codes or technical references. Those
belong in `docs/backend-tasks.md`. Rules: `.claude/skills/handoff-docs/SKILL.md`.

The product spec answers almost everything. The questions below are the few places where it
doesn't, where it says two different things, or where the app already behaves differently from what
it says. Each one says what happens today and what we need decided.

Once a question is answered **and** the app has been updated to match, it is removed from this list.
When an answer needs backend work first, that work is tracked in `docs/backend-tasks.md` and the
question is removed here.
